# 大古截图工具需求文档

## 1. 产品定位

大古截图是运行在 ZTools 中的图片文字处理插件。ZTools 根据输入类型和用户选择进入对应功能路由，插件主页面负责图片 OCR、文字翻译和配置，图片编辑器负责截图或图片标注。

## 2. 指令与路由

插件保留四个清晰的入口，各入口的开始步骤不同：

- `截图`：隐藏主窗口后在光标所在显示器启动沉浸式截图覆盖层；用户直接在全屏冻结画面上框选、标注，并可复制、保存、固定到屏幕或交给 `OCR`/`翻译`。
- `编辑图片`：接收 ZTools 图片输入，或在无图片时显示上传面板；进入普通图片编辑器，不显示截图专用下一步按钮。
- `图片 OCR`：接收 ZTools 图片后直接识别；没有剪贴板图片时显示上传面板。
- `翻译文字`：接收文字输入并翻译；没有文字时显示文字输入面板，不显示图片上传面板。

截图、图片 OCR 和翻译不是同一个入口，因为它们对应 ZTools 不同的输入类型和起始步骤；截图入口保留覆盖层中的 OCR/翻译分支，避免把截图、图片和文字输入混在一个路由里。宿主不支持桌面捕获源或采集失败时，`截图` 回退到 ZTools 系统截图加图片编辑器流程。

## 3. OCR 与翻译

### 3.1 OCR

- 支持 ZTools 图片输入、剪贴板图片、上传图片和截图编辑后的图片。
- 图片进入 OCR 后显示预览和可编辑结果；图片标题行提供「预览」折叠/展开、「复制」与「编辑」入口，不再占用一整行放编辑按钮。
- 图片与文字框等宽（1:1），图片容器与 OCR 输入框容器上下对齐、高度一致；预览框内可滚轮放大（以光标为锚点）与按住拖动，缩小到原始倍数后复位，缩放只影响查看。
- 无可用 OCR Provider 时提示选择 Provider；不因失败自动切换其他 Provider。

### 3.2 翻译

- 支持 ZTools 文字输入、OCR 结果翻译和截图编辑器的翻译按钮。
- 支持自动检测，以及中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、泰语、越南语、印度尼西亚语、马来语、土耳其语、荷兰语、波兰语、乌克兰语、印地语、捷克语和瑞典语。
- 常见翻译服务通过统一语言目录适配各自语言码，包括微软、百度、阿里、Google、DeepL、有道、腾讯和 MyMemory。
- OCR Provider 与 Translation Provider 分开配置；每一类只启用一个当前选择的 Provider。
- 可发现并选择 ZTools 暴露的同类型 Provider，也可选择插件内置的百度、阿里 Provider。
- Provider 调用失败只提示当前 Provider 的错误，不自动 fallback。
- MyMemory 不再内置默认 key，必须由用户配置 key 后才能使用。

## 4. 图片编辑

- 截图与「编辑图片」共用同一套标注界面：截图覆盖层负责冻结画面与框选，图片编辑器直接打开图片，只有一处标注实现。
- 支持选择、形状（矩形/椭圆）、线条（直线/箭头/双向）、画笔、荧光笔、马赛克、文字、橡皮擦，以及撤销、重做、复制、保存、固定到屏幕和快捷键。
- 编辑界面始终提供 `OCR`、`翻译` 按钮，编辑结果可回传主页面继续识别或翻译。
- 主页面（识别、翻译、配置）统一为 800×600（4:3，宿主主窗口内容宽度固定 800px）窗口；截图覆盖层与按图片尺寸适配的编辑窗口不在此约束内。
- 识别与翻译结果页的操作按钮为「复制」，复制后停留当前页面，可继续翻译、重新识别或清空；原文与译文各自在标题行右上角提供复制入口，译文复制只复制译文；结果页不设底部状态栏，状态提示与历史/配置并入操作行右端，操作栏横跨图片与结果两栏、贴在两容器底部，图片 OCR 页与翻译页位置一致；主题色只用于主操作，状态提示语与历史、复制、编辑等次级入口使用次级字体色。

### 4.1 沉浸式截图

- 覆盖层窗口铺满光标所在显示器（包含任务栏区域），内部绘制冻结画面；不出现深色背景容器。
- 冻结画面支持滚轮缩放（以光标为锚点）与空格/中键拖动平移；缩放只影响查看，导出仍使用选区内的原始像素。
- 拖拽框选区域，显示蓝色边框、八个手柄与 `宽 × 高 px` 尺寸标签，选区外加深遮罩；支持拖动移动与手柄调整大小。
- 工具包含选择、形状（矩形/椭圆、描边/填充）、线条（直线/箭头/双向）、画笔、荧光笔、马赛克、文字、橡皮擦，并提供颜色、粗细、字号与马赛克粒度设置。
- 操作包含撤销、重做、复制、保存 PNG、固定到屏幕、OCR、翻译与取消；没有选区时以整屏作为输出范围。
- 固定到屏幕生成置顶图片窗口，可拖动移动、滚轮缩放，双击或 Esc 关闭。
- 采集失败时把现场写入系统临时目录的 `dagu-capture-status.json`，并回退到系统截图流程。

### 4.2 截图性能

- 触发「截图」的瞬间即向宿主申请画面（预抓帧），与覆盖层窗口创建、页面加载并行；覆盖层优先取用这一帧，取到后立即进入框选。
- 预抓帧写入本地存储的临时键，覆盖层取用即删；主窗口抓帧失败时写入失败标记，覆盖层立即自行采集，不做无谓等待。

## 5. 配置与存储

- Provider 选择、语言偏好和是否同步密钥等偏好优先保存到 ZTools `dbStorage`，没有该 API 时使用本地存储兜底。
- Provider 密钥默认只保存在本机；开启“同步密钥”后额外写入 `dbStorage` 的同步副本，因此可随 ZTools 备份同步。
- 关闭“同步密钥”会删除同步副本，但保留本机密钥。
- OCR 历史始终只保存在本机。
- 启动时兼容并迁移旧的 `ocr_config` localStorage 配置。
- 密钥同步依赖 ZTools 存储本身的安全边界，界面明确提示该存储未声明端到端加密。

## 6. 测试要求

- 单元测试覆盖路由、单 Provider 选择、无 fallback、MyMemory key、存储迁移和密钥同步。
- Chrome E2E 覆盖主页面上传、剪贴板图片、无剪贴板上传、文字翻译、配置、普通编辑、截图编辑器 OCR/翻译和标注工具。
- 集成链路不得跳过 OCR/翻译 Provider 节点；测试中使用可控的 ZTools Provider mock，生产运行时使用真实 ZTools Provider API 或内置 Provider。
- E2E 使用系统安装的 Chrome，不下载 Playwright 自带浏览器。
