# ZTools 单色图标会被自动反色

## 约束

`plugin.json` 的 `logo` 与功能图标不要做成"单一色块 + 透明背景"的纯色图标。否则在暗色主题下，ZTools 会把图标整体反相显示。

## 原因与后果

ZTools 渲染图标用的是 `AdaptiveIcon` 组件：它调用主进程 `analyzeImage()` 分析图标（采样主色、同色占比、透明比例），当判定为"纯色图标"时，会按 `isDark` 与图标亮度决定是否加 `filter: invert(1)`。

判定条件（ZTools 主进程源码）：同色占比 `> 0.85`、透明像素比例 `> 0.1`、不透明像素 `> 20`。满足即 `needsAdaptation: true`。

后果：蓝色 `#2563EB` 被整体反相成黄色 `#DA9C14`，看起来像"图标做错了颜色"，实际源文件完全正常（源码、`dist/`、已安装目录三处一致）。

## 来源

- 本项目 `plugin/icon.png` 曾命中该判定（相似度 0.909、透明比 0.385），启动器里显示为黄色。
- 处理方式：在蓝色主体上叠加约 0.24 的轻微渐变，相似度降到 0.06，判定变为 `needsAdaptation: false`，视觉上仍是蓝色。
- 校验脚本可用 ZTools 的同一算法离线跑（采样 1600 点、颜色阈值 30），不必反复重启客户端。
